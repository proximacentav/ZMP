Проблема неработающего эквалайзера в медиаплеере, где Preamp, speed и pitch работают, а эквалайзер нет.

**Причина:** Использовался один эффект `BASS_BFX_PEAKEQ` с индексом, но BASS требует отдельного эффекта для каждой полосы фильтрации.

**Решение:**
1. Создать массив из 32 эффектов PEAK EQ в AudioManager
2. Создавать 32 эффекта при загрузке файла
3. Устанавливать параметры для каждого эффекта по индексу
4. Добавить логирование через qDebug() для отладки

**Ключевые изменения:**
- equalizerwidget.h: добавлено `static const int NUM_BANDS = 32`
- equalizerwidget.cpp: 32 полосы с частотами от 5 Гц до 25 кГц (логарифмический шаг)
- audiomanager.h: добавлен `HSTREAM m_eqFX[32]` и `QVector<double> m_bands`
- audiomanager.cpp: создание 32 эффектов, функция `setEqualizerGain` с логированием

**Диапазон:** -500...+500 dB, точечные пики (без ширины полосы)

**Проверка:** Компиляция `make -j4`, запуск плеера, изменение ползунков, проверка логов в консоли.
